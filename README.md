## About me

I'm a Senior Mobile Engineer with 8+ years building cross-platform apps in Flutter and React Native, and 15+ years in tech overall. Today I work on a production healthcare app, owning features end to end — from architecture to store release.

Alongside mobile work, I build AI integrations: LLM APIs (Claude, OpenAI), n8n workflows and WhatsApp automation for small businesses. In practice, this means I can ship the app and also the intelligent systems around it.

Some things I've done:

- Cut page load times by up to 80% and crash rates by up to 40% through profiling, widget-tree optimization and Crashlytics-driven debugging.
- Migrated a legacy Ionic app to Flutter and brought an inherited codebase to 95% test coverage with Mockito.
- Set up CI/CD pipelines (GitHub Actions, Bitrise, Fastlane) that shortened deploys and kept releases compliant with App Store and Google Play rules.
- Built apps from scratch using Clean Architecture, and maintained apps inherited from other teams.
- Mentored junior and mid-level developers and led code reviews.
